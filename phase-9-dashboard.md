# Phase 9: Build a Dashboard

## Steps
1. In the navigator filter, type `pa_dashboards.form` and press Enter to open the dashboard form.
2. If it will not open, open the ACL record for **pa_dashboards** (operation: Create), turn on **Admin overrides**, and click Update. Then try again.
3. Name the dashboard **Staff Insights Dashboard** and save it.
4. Open each of the three reports in turn: **Share > Add to Dashboards**, select **Staff Insights Dashboard**, and click **Add**.
5. Open the dashboard and confirm all three reports show.
6. Optional: restrict who can see it by users, groups or roles.

A finished Staff Insights Dashboard with all three reports.

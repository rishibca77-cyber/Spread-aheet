# Phase 4: Create and Run the Transform Map

## Steps
1. Name: **Staff Spreadsheet Load**.
2. Source table: **Staff Import** (auto-filled).
3. Target table: **Staff Directory**.
4. Click **Auto Map Matching Fields**.
5. Open **Mapping Assist** and check that each source field maps to the matching target field.
6. Click **Save**.
7. Click **Transform** and confirm the run finishes with a success message.

## Video narration
"The Transform Map tells ServiceNow which source column goes to which target field. I use Auto Map, check it in Mapping Assist, then run the transform."

## Result
The rows from Staff Import are copied into Staff Directory.

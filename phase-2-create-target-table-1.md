# Phase 2: Create the Target Table

**Navigation:** All > System Definition > Tables > New

## Steps
1. Label: **Staff Directory**
2. Name: `u_staff_directory` (auto-filled).
3. Click **Submit/Save**.
4. Open the table again and go to its form layout (form context menu > Configure > Form Layout).
5. Add these fields, all of type **String**:
   - Employee ID
   - Employee Name
   - Email
   - Department
   - Location
6. Click **Save**.
7. Check that all five fields appear on the form.

## Video narration
"Next I create the table that will hold the final records. I call it Staff Directory and add five string fields that match my spreadsheet columns."

## Result
A custom table, `u_staff_directory`, with five fields ready to receive data.
